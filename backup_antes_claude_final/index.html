Importar dados

Colunas reconhecidas pelo nome do cabeçalho (a ordem não importa, e uma coluna ID — se existir — é ignorada): Data, Conta, Descricao, TipoMovimento, Categoria, Valor, Fixa, Parcela, TotalParcelas, Observacao.
Separador (vírgula, ponto e vírgula ou tabulação) é detectado automaticamente. Data no formato DD/MM/AAAA. Valor aceita formato brasileiro: 1234,56, R$ 1.234,56, -123,45 ou (R$ 123,45) (parênteses = negativo). Linhas em branco são ignoradas. Linhas repetidas (mesma data+conta+descrição+valor) também são ignoradas automaticamente.

⚠️ O arquivo gerado não contém um rótulo e pode exigir rotulagem manual antes de ser salvo ou compartilhado para proteger os dados.
